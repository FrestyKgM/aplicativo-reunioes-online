# Aplicativo de Reuniões On-line

Este repositório contém a documentação de um projeto de aplicativo móvel de reuniões on-line para Android e iOS.

O sistema tem como objetivo oferecer uma plataforma simples, segura e acessível, utilizando tecnologias gratuitas e de código aberto.

## Documentação

* [Análise de mercado](docs/01-analise-de-mercado.md)
* [Proposta de arquitetura](docs/02-proposta-de-arquitetura.md)
* [Padrões de interface](docs/03-padroes-de-interface.md)

## Tecnologias propostas

* Flutter e Dart;
* NestJS e TypeScript;
* PostgreSQL;
* Redis;
* WebRTC;
* LiveKit;
* Coturn;
* Docker.

## Objetivo do projeto

Desenvolver um aplicativo de reuniões on-line que funcione em Android e iOS, com interface simples, baixo consumo de recursos, comunicação em tempo real e possibilidade de utilização sem dependência de assinaturas de software.

## Status

Projeto em fase de análise e planejamento.
