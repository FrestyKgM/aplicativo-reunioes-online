# Requisitos Não Funcionais

## Objetivo

Este documento apresenta os requisitos não funcionais do MeetPoint, definindo características relacionadas à qualidade, desempenho, segurança e usabilidade do sistema.

---

## Requisitos

| Categoria | Requisito |
|-----------|-----------|
| **Usabilidade** | A interface deverá ser simples, intuitiva e permitir que as principais funções sejam executadas com poucos toques. |
| **Desempenho** | O aplicativo deverá responder rapidamente às ações do usuário e adaptar a qualidade do áudio e vídeo conforme a conexão de internet. |
| **Segurança** | A comunicação deverá utilizar HTTPS e autenticação segura, protegendo os dados dos usuários e das reuniões. |
| **Disponibilidade** | O sistema deverá estar disponível sempre que possível, garantindo estabilidade durante as reuniões. |
| **Compatibilidade** | O aplicativo deverá funcionar em dispositivos Android e iOS, adaptando-se a diferentes tamanhos de tela. |
| **Escalabilidade** | A arquitetura deverá permitir a adição de novos usuários e funcionalidades sem comprometer o desempenho. |
| **Manutenibilidade** | O código deverá seguir padrões de desenvolvimento, facilitando correções e futuras melhorias. |
| **Confiabilidade** | O sistema deverá minimizar falhas e tentar reconectar automaticamente em caso de perda de conexão. |
| **Acessibilidade** | O aplicativo deverá oferecer suporte a leitores de tela, ajuste de fonte, contraste adequado e legendas. |
| **Portabilidade** | O sistema deverá utilizar Flutter para permitir o desenvolvimento de uma única aplicação para Android e iOS. |

---

## Conclusão

Os requisitos não funcionais definidos contribuem para que o MeetPoint ofereça uma experiência segura, estável e de fácil utilização, além de facilitar sua manutenção e evolução ao longo do tempo.
