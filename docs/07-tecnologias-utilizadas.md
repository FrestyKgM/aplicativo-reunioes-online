# Tecnologias Utilizadas

## Objetivo

Este documento apresenta as principais tecnologias que serão utilizadas no desenvolvimento do MeetPoint e a finalidade de cada uma delas.

---

## Tecnologias

| Tecnologia | Finalidade |
|------------|------------|
| **Flutter** | Desenvolvimento do aplicativo para Android e iOS com uma única base de código. |
| **Dart** | Linguagem utilizada no desenvolvimento do aplicativo. |
| **NestJS** | Desenvolvimento do backend e da API do sistema. |
| **TypeScript** | Linguagem utilizada no backend. |
| **PostgreSQL** | Banco de dados principal para armazenamento das informações. |
| **Redis** | Armazenamento temporário de sessões e cache. |
| **WebRTC** | Comunicação em tempo real para áudio e vídeo. |
| **LiveKit** | Gerenciamento das salas de reunião e transmissão de áudio e vídeo. |
| **Coturn** | Servidor STUN/TURN para garantir conexões estáveis entre os participantes. |
| **Docker** | Padronização e implantação dos serviços da aplicação. |
| **Git** | Controle de versão do projeto. |
| **GitHub** | Armazenamento do código-fonte e da documentação. |

---

## Justificativa

As tecnologias foram escolhidas por serem modernas, gratuitas e amplamente utilizadas no mercado. Essa combinação permite desenvolver um aplicativo multiplataforma, seguro, escalável e de fácil manutenção, reduzindo custos de desenvolvimento e facilitando futuras atualizações do sistema.
